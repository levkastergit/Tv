# Русское ТВ

Приложение для Android TV / Google TV: русские каналы в прямом эфире, без встроенной рекламы.
В приложении нет рекламных баннеров, всплывающих окон и счётчиков. Рекламные паузы, которые канал показывает
в своём эфире, остаются: они входят в сам видеопоток.

Каналы берутся только с официальных бесплатных трансляций (серверы ВГТРК/smotrim.ru, НТВ, rutube.ru, сайты каналов).
Список лежит в [channels.json](app/src/main/assets/channels.json).

## Установка на телевизор

1. На телевизоре установите из Google Play бесплатное приложение **Downloader** (AFTVnews).
2. Откройте его и введите адрес `http://82.23.163.205:40100/tv.apk`.
3. Разрешите Downloader устанавливать приложения, если телевизор спросит, и нажмите «Установить».
4. «Русское ТВ» появится в списке приложений.

## Пульт

| Кнопка | Действие |
|---|---|
| ▲ / ▼ | предыдущий / следующий канал |
| CH+ / CH− | следующий / предыдущий канал |
| Цифры | канал по номеру |
| OK, ◀ или «Меню» | открыть список каналов |
| «Назад» | скрыть список; дважды подряд — выйти |

## Кнопка «Обновить»

Кнопка в начале списка каналов. Она скачивает с сервера обновлений свежий список каналов и, если вышла новая версия,
скачивает её и открывает установщик — останется нажать «Установить».

В первый раз телевизор попросит разрешить «Русскому ТВ» установку приложений. После включения переключателя
Android сам закрывает приложение; откройте его снова — обновление продолжится автоматически.

При каждом запуске приложение тихо забирает свежий список каналов и подсказывает, если вышла новая версия.

## Сервер обновлений

Файлы для кнопки «Обновить» раздаёт [serve.py](serve.py) из папки `server` на порту 40100
(адрес задан в `UPDATE_SERVER` в [app/build.gradle](app/build.gradle)). Запуск — [start-server.cmd](start-server.cmd),
сервер работает в свёрнутом окне, закрыть окно — остановить сервер.

## Выпуск обновления

1. Внести изменения. Чтобы поменять только каналы — править `app/src/main/assets/channels.json`, версию поднимать не нужно.
2. Для новой версии приложения увеличить `versionCode` (и `versionName`) в `app/build.gradle`.
3. Собрать: `gradle assembleRelease`.
4. Выложить: `powershell -ExecutionPolicy Bypass -File publish.ps1`.

## Ключ подписи

Обновление ставится поверх старой версии, только если подписано тем же ключом. Ключ `russkoetv.jks`
и пароли к нему в `keystore.properties` не хранятся в git — сделайте их резервную копию.
Без них новые версии придётся ставить, удалив приложение с телевизора.

Нужны JDK 17 и Android SDK (платформа 34).
